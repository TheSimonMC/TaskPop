📌 TaskPop
  A playful, visual task / todo / project management web app with a pinboard & pop-it inspired design.

✨ What is TaskPop?

  TaskPop is a browser-based task and project management application built with vanilla HTML, CSS, and JavaScript.
  It focuses on a visual pinboard-style workflow, where tasks are represented as movable cards that can be freely arranged, dragged between zones, and organized into projects.
  The goal of TaskPop is to make task management:
    more visual
    more fun
    and less overwhelming
    
🧩 Features

  📁 Multiple projects (tabs)
  📌 Pinboard-style draggable task cards
  ✅ Todo / Doing / Done workflow
  🔍 Search, filter & sorting
  🎨 Colorful task cards
  🌙 Light & Dark mode
  🌍 English & German language support
  💾 Local backups (export & import)
  🔀 Import options:
    Import as new projects
    Merge into current project
  📱 Responsive (desktop & mobile friendly)
  ⚡ Pure vanilla JS (no frameworks)

🚀 How to use

  Clone or download this repository
  Open index.html in your browser
  Start creating projects and tasks
  or use https://thesimonmc.github.io/TaskPop/


📦 Backup & Import

  You can export your data as a .json backup file
  Import backups later with a choice to:
  import projects separately
  or merge tasks into the current project
